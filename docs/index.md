# 神奈川県会場検索サイト

神奈川県内のスタジアム、アリーナ、ホール、ライブハウスを
検索できるWebアプリです。

## 公開アプリ

[神奈川県内会場検索サイトを開く](https://app-practice-mochi-toya1.streamlit.app/)

## 主な機能

- 会場名・種別による検索
- 写真付きの会場一覧
- 会場の概要、歴史、開催実績
- 最寄り駅・周辺スポット・公式リンク
- 会場ごとの口コミ投稿
- 写真の出典表示

## 対象の会場

Kアリーナ横浜、横浜アリーナ、横浜スタジアム、PIA ARENA MM、
パシフィコ横浜など、神奈川県内の代表的な会場を掲載しています。
